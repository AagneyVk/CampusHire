# CampusHire

CampusHire is a DBMS-focused Student Internship & Recruitment Management System for colleges and universities.

This repository is being implemented as a full-stack academic project with:

- React + Vite frontend
- Node.js + Express backend
- MySQL 8+ relational database
- Docker Compose development environment
- JWT authentication and role-based authorization
- Reproducible synthetic dataset generation
- SQL views, indexes, constraints, joins, aggregates, subqueries, and transactions

## Architecture

```text
User
  ↓
React Frontend
  ↓ REST/HTTP
Express Backend
  ↓ parameterized SQL
MySQL
```
